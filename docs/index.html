Buffer en boucle continue

L'écran s'enregistre en permanence sur un segment tournant. Une seule touche fige les dernières secondes dans un fichier — le reste n'a jamais existé sur le disque.

Segments d'1s · ré-écrits en continu

Une source audio à la fois

Micro, tout le système, ou une seule application isolée — Discord ou le jeu, jamais les deux mélangés si vous ne le voulez pas. Basé sur l'isolation par processus de WASAPI.

Capture par processus · Windows 10+

Léger, vraiment

Capture d'écran directe au niveau GPU et encodage matériel quand la carte le permet. Pas de superposition d'effets, pas d'overlay lourd — juste ce qu'il faut pour enregistrer.
